Rivet Notes keeps markdown in plain folders. You can edit in place, look at properties, follow links, and see todos as a list or a board.

![Rivet Notes in live mode, in the pink scheme](/rivet-web/screenshots/notes-live-wide.png)

The current downloads are on the [Notes page](/rivet-web/notes/). Vault settings and the key list are in the [Notes README](https://github.com/ulinaaron/rivet-apps/blob/main/apps/notes/README.md).
