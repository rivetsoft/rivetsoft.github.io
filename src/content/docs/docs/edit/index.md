Rivet Edit is a lightweight editor for folders and files. Preferences and the quick panel open with `Ctrl+P`, the same way as the other apps.

The current downloads are on the [Edit page](/rivet-web/edit/). The key table, including `Shift+Ctrl+P`, `Ctrl+O`, and `Ctrl+G`, is in the [Edit README](https://github.com/ulinaaron/rivet-apps/blob/main/apps/edit/README.md).
