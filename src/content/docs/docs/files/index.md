title: Rivet Files
description: A Linux file manager drawn with egui, with no GTK or Qt.
---

Rivet Files is a file manager in the same family as Dolphin, Nemo, Thunar, and Caja. It is a Rust and egui app, with no GTK or Qt. It also runs on its own, and the shell can use it as the Open and Save picker.

The longer feature list, the libraries it needs, and the current downloads are on the [Files page](/rivet-web/files/). Press F1 in the app for the shortcut list. Two paths that are already in use:

- Filters: `~/.config/rivet/filters`
- Actions: `~/.local/share/rivet/actions`

The full shortcut and config map is in the [Files README](https://github.com/ulinaaron/rivet-apps/blob/main/apps/files/README.md).
