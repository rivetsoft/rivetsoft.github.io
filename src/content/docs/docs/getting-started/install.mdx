Unpack the archive and run `install.sh`. That puts the program in `~/.local/bin` and in your launcher. It does not ask for a password.

<InstallCommands slugs={["files", "notes", "edit", "terminal", "ftp"]} />

Each app page has the AppImage too, and Files has a Flatpak. Rivet Shell has no release yet. Build it from the [Shell page](/rivet-web/docs/shell/).

## Welcome

Welcome is optional. Install it the same way if you want it to download and update the apps.
