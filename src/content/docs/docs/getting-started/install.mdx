Each app has its own release. Download that archive and run `install.sh`. Welcome, at the end of this page, can do the same thing later if you want it.

<Aside type="caution" title="Pre-releases">
FTP 0.3.0 and Welcome 0.1.0 are pre-releases. Files 0.8.0, Notes 0.3.0, Edit 0.2.0, and Terminal 0.2.0 are regular releases.
</Aside>

## Prerequisites

<Aside type="note" title="No password for the installer">
`install.sh` copies the program to `~/.local/bin` and adds a launcher entry. The builds are linked against glibc 2.31, so Ubuntu 22.04 and Debian 12 are fine. The AppImage already includes the keyboard libraries below.
</Aside>

A full desktop usually has these libraries. A minimal install often does not. Rivet prints the install command if one is missing.

<Tabs syncKey="distro">
  <TabItem label="Debian and Ubuntu">
    ```sh
    sudo apt install libxkbcommon0 libxkbcommon-x11-0 libxcb-xkb1
    ```
  </TabItem>
  <TabItem label="Fedora">
    ```sh
    sudo dnf install libxkbcommon libxkbcommon-x11
    ```
  </TabItem>
  <TabItem label="Arch">
    ```sh
    sudo pacman -S libxkbcommon
    ```
  </TabItem>
  <TabItem label="openSUSE">
    ```sh
    sudo zypper install libxkbcommon0 libxkbcommon-x11-0
    ```
  </TabItem>
</Tabs>

## Install an app

<Steps>

1. Download the archive. The file name matches the command in the next step.

2. Unpack it and run the installer.

   <Tabs syncKey="app">
     <TabItem label="Files">
       [rivet-files-0.8.0-x86_64-linux.tar.gz](https://github.com/ulinaaron/rivet-apps/releases/download/v0.8.0/rivet-files-0.8.0-x86_64-linux.tar.gz)

       ```sh
       tar xzf rivet-files-0.8.0-x86_64-linux.tar.gz
       cd rivet-files-0.8.0-x86_64-linux
       ./install.sh
       ```

       `./install.sh --default` makes Rivet Files the default file manager. Other downloads, including a Flatpak when the release has one, are on the [Files page](/rivet-web/files/).
     </TabItem>
     <TabItem label="Notes">
       [rivet-notes-0.3.0-x86_64-linux.tar.gz](https://github.com/ulinaaron/rivet-apps/releases/download/rivet-notes-v0.3.0/rivet-notes-0.3.0-x86_64-linux.tar.gz)

       ```sh
       tar xzf rivet-notes-0.3.0-x86_64-linux.tar.gz
       cd rivet-notes-0.3.0-x86_64-linux
       ./install.sh
       ```

       Other downloads are on the [Notes page](/rivet-web/notes/).
     </TabItem>
     <TabItem label="Edit">
       [rivet-edit-0.2.0-x86_64-linux.tar.gz](https://github.com/ulinaaron/rivet-apps/releases/download/rivet-edit-v0.2.0/rivet-edit-0.2.0-x86_64-linux.tar.gz)


3. Open the app from your launcher. From a terminal the commands are `rivet`, `rivet-notes`, `rivet-edit`, `rivet-terminal`, and `rivet-ftp`.

</Steps>

## Welcome

<Aside type="tip" title="Optional">
Skip this if the apps above are enough. Welcome installs and updates them from one window.
</Aside>

<Steps>

1. Download [rivet-welcome-0.1.0-x86_64-linux.tar.gz](https://github.com/ulinaaron/rivet-apps/releases/download/rivet-welcome-v0.1.0/rivet-welcome-0.1.0-x86_64-linux.tar.gz) and install it.

   ```sh
   tar xzf rivet-welcome-0.1.0-x86_64-linux.tar.gz
   cd rivet-welcome-0.1.0-x86_64-linux
   ./install.sh
   ```

2. Open it with `rivet-welcome`.

</Steps>

There is also an [AppImage](https://github.com/ulinaaron/rivet-apps/releases/download/rivet-welcome-v0.1.0/Rivet_Welcome-0.1.0-x86_64.AppImage). What Welcome does after it is installed is on the [Welcome page](/rivet-web/docs/welcome/). The terminal commands are in the [Welcome README](https://github.com/ulinaaron/rivet-apps/blob/main/apps/rivet-welcome/README.md).

## Shell

Rivet Shell has no release yet. From a checkout of the repository:

```sh
cargo build --release -p rivet-shell
```

The run commands, and which compositors it supports, are on the [Shell page](/rivet-web/docs/shell/).
