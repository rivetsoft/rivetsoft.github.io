The usual way in is the Welcome AppImage. Download it, make it executable, and run it. From the window that opens, install the apps you want.

<Aside type="caution" title="Pre-release">
Welcome 0.1.0 is a pre-release. It installs Files, Notes, Edit, Terminal, and FTP from their GitHub releases.
</Aside>

## Get started

<Steps>

1. Download [Rivet_Welcome-0.1.0-x86_64.AppImage](https://github.com/rivetsoft/rivet-apps/releases/download/rivet-welcome-v0.1.0/Rivet_Welcome-0.1.0-x86_64.AppImage).

2. Make it executable and run it.

   ```sh
   chmod +x Rivet_Welcome-0.1.0-x86_64.AppImage
   ./Rivet_Welcome-0.1.0-x86_64.AppImage
   ```

3. In Welcome, install the apps. They land in `~/.local/bin` and in your launcher. Welcome does not ask for a password.

</Steps>

What Welcome does after that is on the [Welcome page](/docs/welcome/). The terminal commands are in the [Welcome README](https://github.com/rivetsoft/rivet-apps/blob/main/apps/rivet-welcome/README.md).

## Alternative methods

Each app also has its own release. The archive runs `install.sh`. An AppImage is one file you run directly.

<Aside type="note" title="Libraries for the archive">
The AppImage already includes the keyboard libraries. The archive build needs them on a minimal system. A full desktop usually has them. The builds are linked against glibc 2.31, so Ubuntu 22.04 and Debian 12 are fine. `install.sh` does not ask for a password.
</Aside>

<Tabs syncKey="distro">
  <TabItem label="Debian and Ubuntu">
    ```sh
    sudo apt install libxkbcommon0 libxkbcommon-x11-0 libxcb-xkb1
    ```
  </TabItem>
  <TabItem label="Fedora">
    ```sh
    sudo dnf install libxkbcommon libxkbcommon-x11
    ```
  </TabItem>
  <TabItem label="Arch">
    ```sh
    sudo pacman -S libxkbcommon
    ```
  </TabItem>
  <TabItem label="openSUSE">
    ```sh
    sudo zypper install libxkbcommon0 libxkbcommon-x11-0
    ```
  </TabItem>
</Tabs>

```sh
tar xzf rivet-welcome-0.1.0-x86_64-linux.tar.gz
cd rivet-welcome-0.1.0-x86_64-linux
./install.sh
```

### Shell

Rivet Shell has no release yet. From a checkout of the repository:

```sh
cargo build --release -p rivet-shell
```

The run commands, and which compositors it supports, are on the [Shell page](/docs/shell/).
