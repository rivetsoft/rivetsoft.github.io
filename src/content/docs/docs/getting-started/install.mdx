There are three ways to install a Rivet app, and every app has all three:

- **Rivet Welcome** installs and updates the apps for you. This is the usual way.
- **An AppImage** is one file you run. Nothing is installed.
- **The portable build** is an archive with `install.sh`, which installs the app for your user. It is the same file Welcome installs.

The apps are {releaseApps.map((app) => app.name).join(', ')}. Each release also has GitHub's archive of the source code at its tag.

## Get started

<Steps>

1. Download the Welcome AppImage, make it executable, and run it.

   <InstallDownloads kind="appimage" slug="welcome" />

2. In Welcome, install the apps. They land in `~/.local/bin` and in your launcher. Welcome does not ask for a password.

</Steps>

What Welcome does after that is on the [Welcome page](/docs/welcome/). The terminal commands are in the [Welcome README](https://github.com/rivetsoft/apps/blob/main/apps/rivet-welcome/README.md).

## Alternative methods

Each app also has its own release, with an AppImage and a portable build.

<Aside type="note" title="Libraries for the portable build">
The AppImage already includes the keyboard libraries. The portable build needs them on a minimal system. A full desktop usually has them. The builds are linked against glibc 2.31, so Ubuntu 22.04 and Debian 12 are fine. `install.sh` does not ask for a password.
</Aside>

## Updating

Welcome checks for new versions from its tray icon and updates the apps it installed. For an AppImage, download the new one and run it in place of the old. For the portable build, run the new release's `install.sh` the same way; it replaces the old version.

## From source

Every app builds from a checkout of [rivetsoft/apps](https://github.com/rivetsoft/apps) with `cargo build --release -p` and the app's package name. The [README](https://github.com/rivetsoft/apps#readme) has the details.
